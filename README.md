# Bad Bunny Vape Bolivia 💨

Tienda online de vapes premium — React + Vite + Tailwind CSS

## Stack
- **React 18** – componentes y estado
- **Vite 5** – bundler ultrarrápido
- **Tailwind CSS 3** – estilos utilitarios
- **Lucide React** – iconografía
